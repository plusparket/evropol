# Инструкции для ИИ-агентов

Проект — сайт компании «Европроект» (europroject.kg, Бишкек): Astro + Postgres + Caddy, всё в Docker.
Сайт-визитка без товаров: каждый раздел ведёт на свой сайт или страницу (поле `sections.link`).
Документация — в [docs/](docs/README.md), журнал изменений — [docs/changelog.md](docs/changelog.md).

## llms.txt и llms-full.txt — всегда актуальны

Сайт отдаёт два файла по стандарту [llmstxt.org](https://llmstxt.org), чтобы ИИ-ассистенты могли прочитать сайт целиком:

- **`/llms.txt`** — обзор: о компании, адрес, телефон, почта, часы работы (если заданы), разделы со ссылками
  на страницу раздела и на сайт раздела, бренды, страницы, новости;
- **`/llms-full.txt`** — всё содержимое: тексты разделов, описания брендов, тексты страниц и новостей.

Файлы не хранятся готовыми, а собираются из базы при каждом запросе: `src/server/llms.ts`
(маршруты `src/pages/llms.txt.ts` и `src/pages/llms-full.txt.ts`).

Правила:

1. **Любое изменение данных сайта сопровождается правкой `src/server/llms.ts`**: новый тип страниц, новое поле
   раздела или бренда, новые контакты в настройках. Изменение без этого считается незаконченным.
2. **Только то, что видно на сайте.** Скрытые разделы, бренды, страницы и черновики новостей в файлы не попадают.
3. **Проверка после изменений:** оба адреса отвечают 200, в `/llms.txt` есть контакты и все опубликованные разделы:

   ```bash
   docker compose exec -T app sh -c "wget -qO- http://127.0.0.1:4321/llms.txt | head -40"
   ```

4. **Запись в журнал:** изменение файлов или их генератора — строка в `docs/changelog.md`.

## Тексты для сайта пишем по скиллу stop-slop

Скилл [stop-slop](.claude/skills/stop-slop/SKILL.md) описывает приметы текста, написанного ИИ, и способы их убрать.
В `.claude/skills/stop-slop/` лежит копия [hardikpandya/stop-slop](https://github.com/hardikpandya/stop-slop) без правок
(лицензия MIT).

**Применяем всегда**, когда пишем или правим текст, который увидит посетитель или поисковик: разделы, бренды,
страницы, новости, блоки главной (`seed/`, `src/server/home.ts`), SEO-заголовки и описания, подписи кнопок,
постоянные тексты в `src/server/llms.ts`.

**Порядок:** прочитать скилл, написать текст, пройти Quick Checks из `SKILL.md`, оценить по пяти шкалам из раздела
Scoring. Меньше 35 из 50 — переписать.

**Русский текст.** Правила те же, с уточнениями:

1. Убираем пустые слова: «очень», «действительно», «просто», «реально», «по-настоящему», «абсолютно», «идеально»,
   «максимально», «уникальный».
2. Не пишем шаблоны: «стоит отметить», «важно понимать», «в современном мире», «идеальное решение»,
   «широкий ассортимент», «высокое качество», «индивидуальный подход», «таким образом», «в заключение».
3. Противопоставления «это не просто пол, а…», «не только…, но и…» убираем и пишем суть прямо.
4. Вопрос с ответом следом («Почему винил? Потому что…») заменяем утверждением.
5. Тире для паузы заменяем точкой, запятой или двоеточием. «X — это Y» перестраиваем. Короткое тире в диапазонах
   («10:00–19:00») оставляем.
6. Действительный залог, к посетителю обращаемся на «вы».
7. Конкретика вместо оценок: класс износостойкости, толщина, гарантия.
8. Данные пишем полностью: адреса, телефоны, часы работы, списки разделов. Названия брендов и пунктов меню не меняем.
