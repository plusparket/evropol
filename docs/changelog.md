## 2026-10-25 — сайты разделов

- У раздела может быть свой сайт с каталогом товаров. Один код, одна база и одна админка: приложение узнаёт сайт
  раздела по адресу запроса (`sections.site_host`), страницы — `src/pages/section-site/`. Caddy принимает адреса
  из `SECTION_SITES_ADDRESS` (локально `http://*.localhost`). Подробно — [section-sites.md](section-sites.md).
- Первый сайт: «SPC / LVT / кварцвинил» на `vinyl.localhost`, 20 товаров BerryAlloc Click Comfort 55
  (`seed/catalog/vinyl.json`, фото производителя скачиваются при запуске). Каталог с фильтрами, страница товара
  с WhatsApp и расчётом упаковок.
- Миграция `002_section_sites.sql`: поля `site_host`, `site_color` у разделов, таблица `products`.
- Админка: «Сайт раздела» в карточке раздела, новый пункт «Товары сайтов разделов».
- Главный сайт: плитки, меню и подвал ведут сразу на сайт раздела, если он включён.
- `/llms.txt` главного сайта даёт адрес сайта раздела; у каждого сайта раздела свои `/llms.txt` и `/llms-full.txt`
  с товарами, а также `sitemap.xml` и `robots.txt`.
- Второй сайт: «Ламинат» на `laminate.localhost`, 15 товаров BerryAlloc Chateau+ (`seed/catalog/laminate.json`),
  бренд BerryAlloc добавлен в раздел. Тексты описаний переписаны по stop-slop. Первичная настройка теперь отдельно
  для каждого раздела (`section_site:<раздел>`), поэтому уже настроенная база получает новый сайт при запуске.
