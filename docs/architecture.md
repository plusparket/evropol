# Архитектура

## Стек

- **Astro 7** в режиме SSR (`@astrojs/node`, standalone): каждая страница собирается из базы при запросе,
  правки в админке видны сразу. Переходы между страницами — `ClientRouter`.
- **PostgreSQL 18**, драйвер `postgres` (postgres.js) с преобразованием имён `snake_case` → `camelCase`.
- **Caddy 2**: HTTPS (Let's Encrypt), сжатие, отдача `/uploads` и статики, повтор запроса при перезапуске приложения.
- **sharp**: загруженные фото сжимаются в WebP нескольких размеров.
- **Docker Compose**: сервисы `db`, `app`, `caddy`; тома `pgdata` и `uploads`.

## Модель сайта

Сайт-визитка без товаров. Главная показывает блоки: главный экран, о компании, карточки разделов, логотипы
производителей, последние новости, контакты. Каждый **раздел** (`sections`) имеет свою страницу `/<slug>`
с описанием и брендами, а поле `link` ведёт на отдельный сайт или страницу раздела, где будут товары и заказ.
Пока ссылки нет, на странице раздела вместо кнопки стоят WhatsApp и телефон.

## Структура

```
db/migrations/        SQL-миграции, применяются по порядку при старте (таблица schema_migrations)
seed/                 контент старого сайта для пустой базы: content.json и pages/*.html
scripts/              start.ts (миграции, сид, сервер, расписание Instagram), migrate, seed, create-admin, instagram-sync
src/server/           работа с базой и бизнес-логика
  sections.ts         разделы и бренды
  home.ts             контент главной (JSON в settings.home_content)
  content.ts          страницы, новости, меню
  settings.ts         настройки сайта и подстановка {{placeholder}} в тексты
  redirects.ts        301 со старых адресов
  seo.ts              заголовки, описания, JSON-LD (Organization, LocalBusiness)
  llms.ts             /llms.txt и /llms-full.txt
  instagram.ts        загрузка постов Instagram в новости
  uploads.ts          приём и сжатие картинок
  auth.ts, admin.ts   вход в админку, сессии, вспомогательные функции
src/pages/            маршруты сайта: index, [...path] (раздел → страница → переадресация → 404), news/, sitemap, robots, llms
src/pages/admin/      админка
src/components/       Header, Footer, Home, SectionView, PageView и др.
src/styles/site.css   оформление сайта; admin.css — админки
src/scripts/          site.ts (меню, кнопка наверх, карты, счётчики), ui.ts (шапка, слайдер, просмотр фото)
public/               шрифты, логотип, иконки
```

## Маршрутизация

`src/pages/[...path].astro` обрабатывает все адреса, кроме главной и новостей:

1. адрес с `/` на конце — 301 на адрес без него;
2. один сегмент и опубликованный раздел с таким `slug` — страница раздела;
3. опубликованная страница из `pages` — текстовая страница;
4. запись в `redirects` — 301 (сравнение без учёта регистра);
5. иначе 404.

Адреса разделов и страниц не должны совпадать: админка это проверяет. Зарезервированные адреса — `RESERVED_SLUGS`
в `src/server/content.ts`.

## Админка

`/admin`, вход по логину и паролю, сессия в cookie (в базе хранится sha256 токена). Разделы меню: Обзор,
Главная страница, Разделы, Бренды, Страницы, Новости, Меню, Настройки сайта, Переадресации, Пользователи.
Тексты редактируются в Jodit. Подробно — [admin-guide.md](admin-guide.md).
