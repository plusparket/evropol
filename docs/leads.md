# Анкета «Оставьте контакты»

На странице «Контакты» под текстом стоит анкета по вопросам сотрудничества (владелец, 11.11.2026): имя, фамилия,
компания, email и кнопка «Отправить».

- Заявка сохраняется в таблице `leads` (миграция `db/migrations/006_leads.sql`) и видна в админке: «Заявки».
- Письмо о заявке уходит на почту из «Настроек сайта» (поле «Почта», сейчас info@evropol.kg). Ответ на письмо
  уходит посетителю (в письме стоит Reply-To с его адресом).
- Письма отправляются только когда в `.env` задан почтовый сервер:

  ```
  SMTP_HOST=smtp.example.com   # сервер исходящей почты почтового хостинга
  SMTP_PORT=465                # 465 — SSL, 587 — STARTTLS
  SMTP_USER=info@evropol.kg    # логин ящика
  SMTP_PASS=…                  # пароль ящика (или пароль приложения)
  SMTP_FROM=info@evropol.kg    # от кого письмо; пусто — SMTP_USER
  ```

  После правки `.env`: `docker compose up -d`. Без SMTP заявки только в админке, в колонке «Письмо» —
  «не отправлялось». Ошибка отправки тоже видна в этой колонке.
- Защита от спама: скрытое поле-ловушка и не больше 5 заявок за 10 минут с одной почты (30 всего).
- Код: `src/components/LeadForm.astro` (анкета), `src/pages/lead.ts` (приём), `src/server/leads.ts`,
  `src/pages/admin/leads.astro`.
