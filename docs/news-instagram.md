# Новости и Instagram

Раздел «Новости и события» (`/news`) показывает записи из админки и посты из Instagram компании
(instagram.com/evropolkg). Посты загружаются официальным Instagram API: подпись без хэштегов становится текстом
записи, фото сохраняются на сайте, внизу записи ссылка на пост. Заголовок — первая строка подписи.
Загрузка включается, когда задан ключ доступа: проще всего вставить его в админке, **«Новости» → «Посты из Instagram»**
(кнопка «Подключить и загрузить посты» проверяет ключ, сохраняет его в базе и сразу загружает последние 24 поста).
Ключ можно задать и в `.env` (`INSTAGRAM_TOKEN`), ключ из админки главнее.

Когда в новостях появляется первый пост Instagram, три новости со старого сайта (`seed/content.json`: запуск сайта,
коллекция ковролина, террасная доска) скрываются: в «Новостях» остаются посты Instagram. Записи не удаляются, их можно
опубликовать снова в админке.

- **Первая загрузка** — посты за последние 90 дней:
  `docker compose exec app node scripts/instagram-sync.ts` (число дней можно указать: `... instagram-sync.ts 30`).
- **Дальше сайт загружает новые посты сам раз в две недели** (`scheduleInstagramSync` в `src/server/instagram.ts`).
  Уже загруженные посты не дублируются.
- **Остаются 24 самых новых поста Instagram** (`KEEP_POSTS`), более старые удаляются вместе с фото.
  Записи, добавленные в админке, не удаляются.

## Ключ доступа

1. Аккаунт Instagram должен быть профессиональным (Настройки → «Тип аккаунта и инструменты» → профессиональный).
2. На https://developers.facebook.com → «Мои приложения» → «Создать приложение», сценарий «Управление сообщениями
   и контентом в Instagram».
3. В приложении: Instagram → «Настройка API со входом через Instagram» → «Создать маркеры доступа» → добавить
   аккаунт evropolkg и разрешить доступ.
4. «Создать маркер», скопировать ключ (начинается с `IG`). Ключ — пароль к постам, никому его не пересылайте.
5. Админка → «Новости» → вставить ключ → «Подключить и загрузить посты». Или в `.env`: `INSTAGRAM_TOKEN=<ключ>`,
   затем `docker compose up -d app` и первая загрузка.

Если приложение для domparketa.kg уже есть, новое создавать не нужно: в нём же «Добавить аккаунт» → evropolkg.
Если Instagram не пускает аккаунт: «Роли приложения» → «Роли» → «Добавить людей» → «Тестировщик Instagram» → evropolkg,
затем в Instagram: Настройки → «Приложения и сайты» → «Приглашения тестировщиков» → принять.

Ключ действует 60 дней; при каждой загрузке сайт продлевает его и хранит в базе (`settings.instagram_token`).
Если сайт был выключен дольше 60 дней, создайте ключ заново и удалите старый:
`docker compose exec -T db psql -U europroject -d europroject -c "DELETE FROM settings WHERE key = 'instagram_token'"`.
