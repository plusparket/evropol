# Европроект (europroject.kg)

Сайт компании «Европроект», Бишкек: напольные покрытия Moduleo, BerryAlloc, Modulyss, Betap, IVC Commercial, BLOQ,
CM Decking и клеи Forbo Eurocol. Сайт заменяет старый сайт на PHP.

Сайт работает как визитка и указатель: товаров и заказа здесь нет. У каждого раздела (Винил, Ковровая плитка,
Строительная химия, Террасная доска, Коммерческий линолеум) есть своя страница, а с неё ссылка на отдельный сайт
раздела с товарами и онлайн-заказом. Ссылки задаются в админке: «Разделы» → раздел → «Сайт раздела».

Стек: Astro (SSR, Node), PostgreSQL, Caddy, Docker Compose. На компьютере нужен только Docker.

## Запуск

```bash
cp .env.example .env        # в Windows: copy .env.example .env
docker compose up -d --build
```

- сайт: http://localhost
- админка: http://localhost/admin (логин и пароль из `ADMIN_LOGIN` / `ADMIN_PASSWORD` в `.env`)

При первом запуске создаются таблицы, первый администратор, а пустая база заполняется текстами, разделами,
брендами, новостями и переадресациями со старого сайта (`seed/`).

Документация: [docs/](docs/README.md). Правила для ИИ-агентов: [AGENTS.md](AGENTS.md).
